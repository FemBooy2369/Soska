# 🧪 Два проекта Windows Forms

Данный репозиторий содержит два небольших учебных проекта на **C# Windows Forms**.

---

## 1. 🎨 Color Picker — Выбор цвета

Удобное приложение для выбора цвета с помощью RGB-ползунков, регулировки яркости и HEX-формата.

### Возможности:
- Три ползунка **R**, **G**, **B** (0–255)
- Ползунок **Яркость** (0–100%)
- Отображение текущих значений рядом с ползунками
- Поддержка ввода и отображения цвета в **HEX**
- Живой предпросмотр цвета
- Кнопки **OK** / **Отмена**

---

## 2. 🔊 Sound Volume Beep — Регулятор громкости со звуком

Приложение с ползунком громкости, анимацией и постоянным звуковым сигналом через системный динамик.

### Возможности:
- Регулировка громкости от 0 до 100
- Анимированная GIF-анимация
- Постоянное воспроизведение звука через `Console.Beep()`
- Кнопка **Замутить / Включить** с сохранением предыдущего уровня
- Динамическое изменение цвета интерфейса в зависимости от громкости

---

## 🔧 Использованные методы и технологии

### Color Picker:
- **TrackBar** — управление R, G, B и яркостью
- **Panel** — предпросмотр цвета
- **TextBox** — работа с HEX-форматом
- **Label** — отображение значений
- `InitializeColorPicker()`, `UpdateColor()`, `TrackBar_Scroll()`, `TxtHex_TextChanged()`

### Sound Volume Beep:
- **TrackBar** — основной элемент управления громкостью
- **PictureBox** — отображение анимированной GIF
- **System.Windows.Forms.Timer** — таймер для генерации звука
- **Console.Beep()** — генерация звуковых сигналов процессора
- **Button** — кнопка «Замутить / Включить»
- `SetupUI()`, `Slider_ValueChanged()`, `SoundTimer_Tick()`, `BtnMute_Click()`, `LoadGif()`

### Общее:
- Полностью программное создание интерфейса (без `.Designer.cs`)
- Работа в одном файле

---

## 🛠 Технологический стек

- **C#**
- **.NET Windows Forms**
- Полностью кодовый интерфейс
- `System.Drawing` (для цвета)
- Работа со звуком через системный динамик (`Console.Beep`)
